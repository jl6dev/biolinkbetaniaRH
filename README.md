Betania Monteiro RH - Página Web

Este é o repositório da página web da Betania Monteiro RH, criada para centralizar informações sobre serviços de Recursos Humanos e facilitar o contato com clientes e parceiros.

A página é responsiva, moderna e acessível, ideal para ser usada como biolink em redes sociais ou divulgação profissional.

🔹 Funcionalidades

Apresentação profissional de Betania Monteiro

Descrição de serviços de RH e consultoria

Links diretos para WhatsApp, com mensagens prontas

Layout moderno, limpo e responsivo (desktop e mobile)

🔹 Tecnologias Utilizadas

HTML5 & CSS3

JavaScript (interatividade simples)
